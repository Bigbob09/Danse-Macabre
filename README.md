# Danse-Macabre
Danse Macabre is a Lorebook/ artbook project set in a dystopian past where sins are manifested into creatures, and humans have been given powers to balance the power of Earth. This is displayed in a web-page format.
## Steps for instillation
1: Download the contents of the repository. <br>
2: If in a compressed ZIP file, Extract the contents to it's own folder. <br>
3: Run the index.html file.
